# 字里行间 · 日记盲测

16 篇角色日记的五维随机盲测网页。

## 使用

打开 index.html，或使用 GitHub Pages 发布 main 分支的根目录。

流程：评分说明 → 人设与聊天记录 → 16 篇随机评分 → 提示词结果对比。

分组：原文 1–7 为提示词 1，8–14 为提示词 2，15–16 为旧提示词。
每个维度 1–5 分，完成全部 80 项评分后展示各组均分和原始总分。

评分仅保留在当前页面，刷新会重置；当前版本不收集或汇总多位测试者的数据。

## 文件

- index.html：网页入口
- style.css：页面样式
- app.js：随机顺序、评分与统计
- data.js：人设、聊天记录与 16 篇日记
